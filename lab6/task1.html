Lab Assignment Questions & Answers

Question: What styles did you apply to each type of selector, and how do they affect the appearance of the elements?

  • Element Selector (`p`): Styles applied: Font family, text color (`#4a5568`), and line height (`1.6`). Effect: Sets a clean baseline readability globally across all standard paragraphs.
  • Class Selector (`.card` & `.highlight-text`): Styles applied: Background color (`#f8f9fa`), borders, padding, rounded corners, font-weight, and blue text color. Effect: Groups content into a distinct visual component and highlights targeted phrases. Because it is a class, it can be reused across multiple elements.
  • ID Selector (`#main-title`): Styles applied: Centered alignment, primary title color (`#2c3e50`), a decorative bottom border accent, and a unique heading font (`Georgia`). Effect: Targets a single unique landmark element on the page, giving it high visual prominence as the primary heading.
